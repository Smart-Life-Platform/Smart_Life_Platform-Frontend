# Аналіз і вдосконалення Smart Life Platform

Дата: 7 листопада 2026 року.


## Що виправлено

### 1. Сортування та фільтрація пріоритетів

Файл: `src/hooks/useTasks.js`.

Раніше сортування використовувало окремий список `high`, `medium`, `low`. Значення `critical`, числові пріоритети старих завдань і невідомі значення отримували індекс −1 та потрапляли перед `high`. Фільтр порівнював значення без нормалізації, тому числовий пріоритет `3` не відповідав вибраному `high`.

Тепер використовується наявний спільний модуль `src/utils/priority.js`. Порядок: `critical`, `high`, `medium`, `low`; невідомі та відсутні значення розміщуються наприкінці. Числові й текстові пріоритети фільтруються узгоджено. Вхідний масив завдань не змінюється.

### 2. Групування завдань календаря

Файл: `src/hooks/useTasks.js`, функція `tasksByDate`.

Раніше кожне додавання копіювало весь уже зібраний масив завдань відповідного дня. Для великої кількості завдань одного дня це призводило до квадратичної кількості операцій копіювання.

Тепер масив кожного дня створюється один раз, а завдання додаються через `push`. Групування виконується за один прохід, зі збереженням порядку та пропуском завдань без дати. Змінюється лише локально створений результат.

### 3. Підрахунок витрат за категоріями

Файл: `src/components/budget/budgetUtils.js`, функція `expensesByCategory`.

Раніше для кожної категорії повторно фільтрувався та підсумовувався весь список витрат. Тепер суми накопичуються за один прохід у `Map`, після чого формується результат для категорій.

Збережено сортування за сумою, округлення відсотків, пропуск порожніх категорій та врахування витрат без відомої категорії у загальній сумі. Складність агрегації зменшено з O(кількість категорій × кількість транзакцій) до O(кількість транзакцій + кількість категорій), без урахування незміненого сортування результату.
